Как пользоваться корпусом

Поисковой механизм корпуса поддерживает поиск по леммам и словоформам как на нивхском, так и на русском. Для нивхских слов полностью поддерживается дополнительный поиск по различным грамматическим признакам; в случае русского языка для словоформ поиск происходит с помощью регулярного выражения по русскому переводу. Русский перевод как для глосс, так и для всего предложения ёфицирован, учитывайте это при поиске по русским леммам или словоформам. Для поиска по лемме нивхских аналогов русских (качественных) прилагательных нужно использовать формулы быть.таким-то («быть.красным», «быть.большим»,...). Леммой для нивхского языка считается голая основа слова без аффиксов, для русского — нормальная форма слова
